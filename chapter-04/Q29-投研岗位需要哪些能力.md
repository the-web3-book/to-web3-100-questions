#  第 29 问：投研岗位需要哪些能力


以下从三个维度展开：各赛道熟悉、投研工具使用、投研报告编写，帮助系统化提升投研水平。

## 一.熟悉各个赛道
在 Web3 与加密投资领域，研究员需要全面理解不同赛道的技术逻辑、商业模式与发展趋势，以便快速评估项目价值和风险。

### 1.钱包（Wallet）
- 角色定位：区块链世界的用户入口与资产安全核心。  
- 重点关注：  
  - Cex Wallet, HD、MPC、AA（智能合约钱包）等技术方案  
  - 私钥管理、安全多签、用户体验  
  - 钱包与支付、跨链资产的联动  
- 投资亮点：用户增长、跨生态适配度、合规性。
  
### 2.DeFi（去中心化金融）
- 核心：无许可金融服务，包括借贷、DEX、衍生品、稳定币。  
- 研究重点：  
  - AMM 模型、风险控制  
  - 收益策略（Lending、Yield Farming）  
  - 协议治理与代币经济模型  
- 关注趋势：合规化、机构资金入场、链上衍生品创新。
  
### 3.公链（Layer1）
- 要点：公链是整个生态的基石。  
- 评估维度：共识机制、开发者生态、TPS 性能、经济激励、安全性。  
- 代表项目：Ethereum、Solana、Aptos、Sui。
  
### 4.Layer2
- 概念：在主链之上扩展性能的解决方案。  
- 关注：Rollup（Optimistic / ZK）、安全性、与主链的桥接。  
- 趋势：模块化设计、低成本高吞吐。
  
### 5.Layer3
- 定位：应用链与特定场景的链上扩展。  
- 研究点：应用专链的商业逻辑、开发工具链、跨链互操作。
  
### 6.DA（数据可用层）
- 作用：保证链上数据可用性与验证效率。  
- 重点：Celestia、EigenDA 等项目的验证机制与经济模型。
  
### 7.LSD（Liquid Staking Derivatives）
- 概念：质押资产的流动性衍生品。  
- 评估：收益率、协议安全、去中心化程度。  
- 趋势：ETH 质押生态扩展、再质押（Restaking）赛道。
  
### 8.跨链互操作
- 目标：资产与信息在多链之间无缝流动。  
- 关注：桥接安全、跨链消息协议、去中心化验证。  
- 典型协议：LayerZero、Wormhole、Axelar。
  
### 9.RWA（Real World Asset）
- 意义：将房地产、债券、碳信用等真实资产上链。  
- 研究要点：合规/KYC、链下资产托管、价格预言机。  
- 机会：传统金融与区块链融合、稳定收益场景。
  
### 10.PayFi（Web3 支付金融）
- 定位：结合支付与去中心化金融的场景。  
- 关注：跨境支付、稳定币、结算速度与监管政策。  
- 未来：与现实商业结合的落地案例。


## 二.投研工具使用

### 1.数据查看工具
投研人员需熟练掌握链上数据平台、金融分析工具和自动化脚本，以实现多维度调研。
- CoinMarketCap
  - 网站链接：https://coinmarketcap.com/
  - 项目介绍：
 全球知名的加密货币行情与数据聚合平台，现已归属 币安（Binance） 旗下。
核心功能：
    - 实时监控不同类型代币的价格、成交量、市场深度
    - 提供 CEX（中心化交易所）与 DEX（去中心化交易所）的交易数据分析
    - 支持市值排名、历史价格趋势、链上流通情况等多维度查询
- CoinGecko
  - 网站链接：https://www.coingecko.com/
  - 项目介绍：
 另一家全球顶尖的加密数据聚合平台。
核心功能：
    - 全面覆盖不同类别代币的交易分析
    - CEX 和 DEX 的交易深度数据
    - NFT 交易分析（独特优势）
    - 代币经济模型及发行机制的可视化展示
- TradingView
  - 网站链接：https://www.tradingview.com/
  - 项目介绍：
 全球领先的金融图表与技术分析平台，广泛用于加密货币、股票和外汇市场。
核心功能：
    - 提供专业级 K 线图表服务
    - 多种技术指标与策略脚本
    - 可与各类交易所 API 连接，实现实时行情与策略回测
- DeFiLlama
  - 网站链接：https://defillama.com/
  - 项目介绍：
 DeFi 领域最权威的 TVL（锁仓量）与数据分析平台。
核心功能：
    - 收录各大公链生态的 DeFi 项目与锁仓数据
    - 详细查询协议 TVL、收益率、链上资金流动
    - 可通过 https://chainlist.org/ 查询所有链的 RPC/ChainID 等网络信息
- DeBank
  - 网站链接：https://debank.com/
  - 项目介绍：
 一站式 DeFi 与链上钱包数据聚合平台。
核心功能：
    - 支持个人钱包资产及协议交互分析
    - 为 B 端机构提供链上数据 API 和可视化服务
    - 覆盖主流公链生态的实时 DeFi 数据
- NFTScan
  - 网站链接：https://nftscan.com/
  - 项目介绍：
 专注于 NFT 数据分析 的综合平台。
核心功能：
    - 提供 NFT 交易量、持有人分布、铸造与销毁记录
    - 支持多链 NFT 数据检索与市场趋势分析
- CryptoRank
  - 网站链接：https://cryptorank.io/
  - 项目介绍：
 强调项目投融资与市场情报的数据平台。
核心功能：
    - 代币与项目全方位信息分析
    - ICO / IDO 项目跟踪与统计
    - CEX 与 DEX 的交易数据
    - 代币解锁时间表与释放节奏分析更深入
- 行业新闻媒体
  - CoinDesk：https://www.coindesk.com/
  - The Block：https://www.theblock.co/
  - Foresight News：https://foresightnews.pro/
  - 链捕手：https://www.chaincatcher.com/
  - 特点：
    - 提供区块链行业深度报道、市场快讯和项目动态
    - 适合获取全球范围内的最新新闻与趋势
- RootData
  - 网站链接：https://www.rootdata.com/
  - 项目介绍：
 聚焦于 项目、资本、人物三维度 的全景化分析平台。
核心功能：
    - 项目分析：基础信息、代币经济模型、团队背景、投资人及其投资组合、关联新闻与社交媒体热度
    - 人物分析：个人经历、参与项目、链上持仓、历史投资记录、社交账号及相关新闻
    - 生态视角：从行业模块切入，剖析特定赛道的整体格局与关联项目

- Bitcoin 生态浏览器
  - Mempool  
    - 链接：https://mempool.space/  
    - 功能：实时查看 Mempool 交易、区块确认进度、符文与铭文数据；全球矿池分布和算力排名；费用估算。
  - OkLink  
    - 链接：https://www.oklink.com/bitcoin  
    - 亮点：Mempool 与区块数据、符文/铭文单独标签显示；全球矿池算力；前 300 大持币地址排名；闪电网络节点与支付通道信息。
  - BtcScan  
    - 链接：https://btcscan.org/  
    - 覆盖区块与链上交易、符文/铭文信息。  
    - 附属站点：https://btcmempool.org/mining  提供详细的 Mempool 及矿池统计。
      
- EVM 链浏览器
  - Etherscan  
    - 主网链接：https://etherscan.io/  
    - 特色：  
      - Blockchain 模块：实时交易、待上链交易、内部合约调用、信标链充值与提现、重组回滚区块、叔块、Top 账户、已验证合约、AA 钱包交易、EIP-7702 抽象账户交易。  
      - Token 模块：热门代币排名、Token Transfer、代币流转可视化。  
      - NFT 模块：热门 NFT、Top Mints、最新交易与转账。  
      - Resource 板块：信标链充提统计、DEX 数据可视化、Gas 费用排行榜、项目目录、快讯、知识库。  
      - More 工具：Gas Tracker、Dex Tracker、Node Tracker、Label Cloud 地址标签。  
    - 商业背景：Etherscan 为 Ethereum、BSC、Polygon、Optimism、Base、Arbitrum 等提供浏览器服务，主网浏览器年费约 150 万美金，测试网约 50 万美金。
  - Oklink：多链支持，功能与 Etherscan 类似，数据可视化更友好。
  - Blockscout：开源 EVM 浏览器，可部署自有链浏览器。
    
- 其他链浏览器
  - Solana：SolScan（https://solscan.io/）  
  - Tron：TronScan（https://tronscan.org/）  
  - 更多：各公链官方或社区提供的浏览器，如 Aptos Explorer、Near Explorer。
  
### 2.项目代码与安全分析
- 源代码审查：GitHub / GitLab：查看开源程度、Commit 频率、贡献者数量、主要维护者活跃度。  
- 合约安全审计：  
  - 查询 Smart Contract Audits 报告，关注已发现漏洞和修复情况。  
  - 参考知名审计机构：Trail of Bits、Quantstamp、CertiK。  
- 漏洞赏金平台： Code4rena、Immunefi 等，用于评估项目应对安全问题的能力及社区反馈。

### 3.社区与社交媒体分析
社区热度往往反映项目的真实影响力和潜在价值。
- 主要渠道：Twitter、Telegram、Discord、Reddit。  
- 辅助工具：  
  - Social Blade、Twitter Audit：检测账号粉丝真实性和活跃度。  
  - GitHub Issues/Community：跟踪社区贡献与开发讨论热度。  
### 4.投资与资金动向
- 募资平台：ICO Drops、CoinList、DAO Maker，获取项目募资与代币分发情况。  
- 商业信息：Crunchbase、LinkedIn，用于追踪团队背景、融资动态。  
- 资金监测：Whale Alert、WhaleStats，用于监控大额链上转账、巨鲸持仓变化。

### 5.研究报告与专家观点
- 研究机构：Messari、Delphi Digital、CoinShares、Electric Capital 等。  
- 专家内容：Podcasts、YouTube 频道、行业峰会演讲。  
- 社区 AMA：关注项目方与核心开发者的问答，第一时间获取未来规划与技术细节。

### 6.数据报表与可视化
- 基础 SQL：学习 SELECT、JOIN、GROUP BY 等语法，便于自定义数据查询。  
- 可视化工具：Tableau、Metabase、Google Data Studio。  
- 链上分析平台：  
  - Dune Analytics：通过 SQL 查询和可视化面板构建自定义数据仪表盘。  
  - Nansen：链上资金流向与地址画像。  
  - Glassnode：比特币、以太坊等宏观链上指标。  
  - Messari：深度研究报告、链上数据汇总。  
  - Footprint Analytics：多链数据可视化与趋势分析。

## 三.投研报告编写
一份高质量投研报告是投资决策的重要依据，需要结构清晰、逻辑严密。
- 报告结构
  - 项目概述：背景、团队、融资情况、竞争格局。  
  - 技术分析：架构、共识机制、代码质量、安全审计结果。  
  - 商业模式：盈利路径、Tokenomics、用户场景。  
  - 市场与竞争：目标市场规模、竞品对比、差异化优势。  
  - 财务与估值：代币分配、解锁计划、估值模型（DCF、PE、TVL 对比）。  
  - 风险评估：政策、技术、市场、团队风险。  
  - 投资结论：核心亮点、潜在隐患、投资建议。
    
- 写作要点
  - 数据驱动：引用链上真实数据与图表支撑观点。  
  - 逻辑严谨：从赛道趋势 → 项目亮点 → 风险对策，层层递进。  
  - 可执行：给出明确的投资策略与后续跟进计划。
    
- 表达技巧
  - 用简洁标题和小节突出重点。  
  - 图表、流程图、Token 分配饼图增强可读性。  
  - 结论前置，让决策者一眼抓住核心信息。
